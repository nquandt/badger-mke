### Blocking issue: the user has only 5 buttons

They said: "up down left right and 'return' or maybe select/back, I'm not sure". The WIP code assumes six
(`BUTTON_UP/DOWN/LEFT/RIGHT/SELECT/BACK`). First, **find out what the 5th button is**: run an `mpremote` poll loop
(see device notes) and have the user press each physical button, printing which `badge.pressed(BUTTON_*)` fires.
Then redesign to fit. Suggested mapping (adjust to the real 5th button, which must double as "back"):

| Button | Logo | Card | Level |
| --- | --- | --- | --- |
| Left/Right | prev/next screen | prev/next card | prev/next |
| Up | play/pause | QR for the current card (toggle) | zero the level |
| Down | contact QR (toggle; press again to switch LinkedIn/GitHub) | QR (same as Up, or unused) | unused |
| 5th (back/select) | on a QR: close it; elsewhere: go home; on logo: exit app via `reset()` | same | same |

Also unresolved: how apps exit. Contacts/Pong call `reset()` on BACK; Snake/Flappy never handle BACK, so the
framework may also exit on its own (maybe a long-press or a button that is not in the six). Find out and make sure
the user can always leave the app.

## Device notes

- Serial: `/dev/cu.usbmodem*`. Run code: `uvx mpremote connect <port> exec "..."` (sandbox must be disabled).
  Any mpremote connection interrupts the running app and blanks the screen; finish with `machine.reset()`.
- `/system` is read-only from MicroPython. Install: `exec "import powman; powman.reset_into_msc()"`, wait ~7 s for the
  `BADGER` volume, copy files, `sync`, `diskutil eject`, then `machine.reset()`. `scripts/install.sh` does all of it.
- `menu/app.py` can be patched (red first tile + icon): `tools/build_menu_patch.py 1.32`, `scripts/install.sh --menu`.
  The original is `menu_patch/app.py.orig`; firmware updates may overwrite `/system`.
- APIs verified on the board: `shape.custom/circle/rectangle/rounded_rectangle/stroke`, `screen.blit` with PNG alpha
  (`image.load`), `image.qr`, `screen.clip = rect(...)`, `screen.measure_text(text, font_size=)`, `badge.imu()`,
  `mat3().translate(vec2).scale(sx, sy)`, RGBA pens via `color.rgb(r, g, b, a)`. MicroPython floats are 32-bit.
- `BUTTON_*` constants and `reset()` are globals inside an app. Settings via `setting("KEY")`.
- Preview (browser): `python3 tools/gen_preview.py`, then serve the repo root (`python3 -m http.server`) and open
  `preview/index.html` (animation) or `preview/states.html` (UI mockup, needs the prepared product images).
